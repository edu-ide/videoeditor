# 제작 가이드

> 60초 조선 야담 영상 제작을 위한 스토리텔링 가이드

## 단계별 제작 프로세스

### 1. 스토리 선정
- [[story-recommendations.md]] 참조
- 1순위: 「폐가에 물려받은 선비」

### 2. 스토리보드 구성 (60초)
| 시간 | 장면 | 내레이션 |
|------|------|----------|
| 0-7초 | 후크: 낡은 폐가가 유산으로 나타남 | "이 폐가를 본 마을 사람들은 모두 도망쳤다..." |
| 7-15초 | 설정: 가난한 선비가 폐가에 입주 | "그만 가라고 만류했지만, 선비는 들어섰다" |
| 15-25초 | 갈등: 처녀귀신이 밤마다 등장 | "밤마다 흰 옷차림의 여인이 찾아왔다" |
| 25-35초 | 고조: "나를 해방시켜 달라"는 간청 | "'나를 자유롭게 해주세요' 그녀는 울먹였다" |
| 35-45초 | 반전: 원한의真相 드러남 | "그녀는 과거 이 집에서 학대한 악한老爷의 피해자였다" |
| 45-55초 | 결말: 선비가 원한을 풀어줌 | "선비는 그녀의 이야기를 들으며 눈물을 흘렸다" |
| 55-60초 | 교훈: 폐가가 다시 살기 좋은 집으로 | "착한 마음은 가장 강력한 마법이다" |

### 3. 시각적 요소 적용
- [[concepts/visual-elements.md]] 참조
- 달빛, 안개, 폐허, 처녀귀신의 반투명 효과

### 4. 오디오 요소
- 배경음악: 전통 국악 (해금, 피리)
- 효과음: 바람소리, 발소리, 울음소리
- 내레이션: 차분한 목소리, 약간 어두운 톤
