# 조선 야담 스토리 위키

> 조선 시대 민담·설화·야담을 영상 제작 관점에서 구조화한 지식 베이스

## 카테고리

### [Entity](entities/)
- 인물: 선비, 처녀귀신, 산신령, 나무꾼, 약초꾼
- 장소: 폐가, 동굴, 산길, 폐허 사원
- 사물: 초상화, 등불, 붉은 실타래, 마법 피리, 흰 사슴의 뿔

### [Concepts](concepts/)
- [스토리 구조](concepts/story-structure.md): 후크→설정→갈등→반전→결말
- [인기 패턴](concepts/popular-patterns.md): 탐욕의 대가, 억울한 죽음의 복수, 초자연적 만남
- [시각적 요소](concepts/visual-elements.md): 달빛, 안개, 등불, 폐허

### [Sources](sources/)
- 유튜브 채널 분석
- 한국민족문화대백과사전 야담 항목
- 고금소총, 청구야담, 계서야담

### [Synthesis](synthesis/)
- [스토리 추천](synthesis/story-recommendations.md): 영상 제작에 적합한 스토리 선정 기준
- [제작 가이드](synthesis/production-guide.md): 60초 영상 제작을 위한 스토리텔링 가이드

## 통계
- 총 스토리: 5개
- 총 엔티티: 12개
- 총 개념: 4개
- 마지막 업데이트: 2026-05-19
