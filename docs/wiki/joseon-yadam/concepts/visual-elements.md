# 시각적 요소

> 영상에서 분위기 연출을 위한 시각적 요소

## 주요 요소

| 요소 | 분위기 | AI 프롬프트 키워드 |
|------|--------|-------------------|
| 달빛 | 신비로움, 고독 | moonlit, ethereal glow |
| 안개 | misterious, 공포 | misty, foggy, atmospheric |
| 등불 | warmth, 위험 | red lantern, glowing, flickering |
| 폐허 | 음산함, abandonment | ruined, abandoned, broken |
| 초상화 | nostalgia, horror | old portrait, faded painting |
| 붉은 실타래 | destiny, connection | red thread, glowing, symbolic |

## 색감 가이드
- **주조색:** 어두운 톤 (검정, 짙은 파랑)
- **accent 색:** 붉은색 (등불, 실타래), 흰색 (한복, 달빛)
- **분위기:** contrast 높은 dark mood
